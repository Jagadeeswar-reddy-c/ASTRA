## Support tiers

| Tier | Architectures | What it means |
|---|---|---|
| **recommended** | Turing (GTX 16xx, RTX 20xx), Ampere (RTX 30xx), Ada (RTX 40xx), Blackwell (RTX 50xx) | Any current driver; llama.cpp **and** vLLM; no driver ceiling, so these can be mixed freely with each other |
| **supported (driver ≤ R580)** | Pascal (GT 1030, GTX 10xx, TITAN Xp), Volta (TITAN V) | Works, but **the whole host must stay on the R580 driver branch**, and engine builds must use CUDA 12.x with every card's architecture. Pascal is llama.cpp-only (vLLM needs cc ≥ 7.0) |
| **best effort (driver ≤ R580)** | Maxwell (GTX 7xx Maxwell, GTX 9xx) | As above, and below ASTRA's qualified compute capability (6.1). Expect to be the slowest stage |
| **unsupported** | Kepler (GTX 6xx/7xx Kepler) and older | No driver supports them together with any current GPU |

Any NVIDIA GPU not in the table (Quadro/RTX A-series, Tesla, laptop GPUs) still works
through its architecture's rules, but has no bandwidth or power figures. The planner
then shows no speed estimate, and the PSU budget uses the driver's power limit.
Figures are for **desktop reference boards**; laptop parts with the same name are
slower and draw less.

## Buying advice for ASTRA

* **Best value per GB for pooling:** RTX 3060 **12 GB** (360 GB/s, 170 W). Avoid the
  8 GB RTX 3060 variant (240 GB/s).
* **Cheap second card that doesn't pin the driver:** GTX 1660 SUPER (6 GB, 336 GB/s,
  125 W) or RTX 2060 (6 GB).
* **Big memory in one card:** RTX 3090 (24 GB) or a 16 GB RTX 4060 Ti / 5060 Ti.
  Check the PSU with `astra compat` first: two 3090s need ≥ 1,200 W.
* **Avoid for pooling:** GT 1030 (2 GB, 48 GB/s, no NVENC; the planner almost always
  leaves it out), and any Pascal/Maxwell card if you want to keep the latest driver.
* x8 cards (RTX 3050, 4060, 5060 families) and the x4 GT 1030 are fine in x16 slots.

Check any combination before buying:

```bash
astra compat --simulate "RTX 3060:12288, GTX 1660 SUPER" --driver 580.95
astra plan   --simulate "RTX 3060:12288, GTX 1660 SUPER" --model qwen2.5-14b --quant q4_k_m
```
